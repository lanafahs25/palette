# 🎨 Palette

Palette is a color-mixing companion that helps artists recreate colors from reference photos using the paints they already own.

## Try Palette

 https://lanafahs25.github.io/palette/

## Features

- Upload a reference image and select a color
- Get paint-mixing recipes for selected colors
- Choose which paints you own
- Save custom colors and palettes
- Sign in with Google to keep your data
- Personal palettes and colors are stored securely per user
